# teks-menjadi-ASCII-art
skrip Bash yang dapat mengonversi teks menjadi ASCII art menggunakan figlet


### jalank Makefile (ketik: make lalu enter)
```bash
make
```
### struktur folder
```bash
~/teks-menjadi-ASCII-art $ ls
Makefile   ascii_art.sh                     README.md  install.log
~/teks-menjadi-ASCII-art $ tree
.
├── Makefile
├── README.md
├── ascii_art.sh
└── install.log

1 directory, 4 files
~/teks-menjadi-ASCII-art $
```
